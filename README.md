# StudCred — NFT-портфолио достижений студента

Учебный проект студентов факультета международных экономических отношений
**Финансового университета при Правительстве Российской Федерации**.

MVP проверяемого цифрового портфолио. Организации (вуз, работодатели, организаторы
мероприятий) выпускают студентам **NFT-бейджи достижений**, которые любой человек может
проверить по ссылке или QR-коду — без регистрации и без раскрытия лишних персональных данных.

Сценарий пилота: Финуниверситет выдаёт студентам ФМЭО бейджи за олимпиады, конференции,
курсы и программы международного обмена, а зарубежные вузы-партнёры и работодатели
(например, банки) могут мгновенно проверить их подлинность.

Бейджи являются **soulbound** (непередаваемыми): достижение принадлежит конкретному
человеку, его нельзя продать или передать другому адресу.

## Технологический стек

| Слой | Технология |
|------|-----------|
| Смарт-контракт | Solidity 0.8.24, стандарт ERC-721 (OpenZeppelin v5) |
| Среда разработки | Hardhat |
| Сеть | Polygon Amoy (тестовая, бесплатные токены из крана) |
| Хранилище метаданных | IPFS (через Pinata) |
| Фронтенд | React + Vite + ethers.js v6 |
| Кошелёк | MetaMask |

## Требования

- Node.js 18+ и npm
- Расширение MetaMask в браузере
- Бесплатный аккаунт на [Pinata](https://app.pinata.cloud) (для IPFS)

## Запуск: быстрый старт (локально, без тестовой сети)

Самый простой способ всё проверить — локальная сеть Hardhat.

```bash
# 1. Установить зависимости контрактов
npm install

# 2. Скомпилировать и прогнать тесты
npm run compile
npm test

# 3. В отдельном терминале запустить локальный блокчейн
npm run node

# 4. Развернуть контракт (адрес и ABI сами попадут во frontend/src/)
npm run deploy:local

# 5. (опционально) выпустить тестовый бейдж
npm run issue:local

# 6. Запустить фронтенд
cd frontend
npm install
npm run dev
```

Фронтенд откроется на `http://localhost:5173`. В MetaMask добавьте локальную
сеть Hardhat (RPC `http://127.0.0.1:8545`, chainId `31337`) и импортируйте один
из приватных ключей, которые печатает `npm run node`.

## Запуск: тестовая сеть Polygon Amoy

```bash
# 1. Скопировать шаблон и заполнить приватный ключ
cp .env.example .env
#   PRIVATE_KEY=0x... (ключ тестового кошелька, БЕЗ реальных денег)

# 2. Получить тестовые токены POL из крана:
#    https://faucet.polygon.technology  (выбрать сеть Amoy)

# 3. Развернуть контракт в Amoy
npm run deploy:amoy

# 4. Настроить IPFS для фронтенда
cd frontend
cp .env.example .env
#   VITE_PINATA_JWT=... (токен из app.pinata.cloud → API Keys)

npm install
npm run dev
```

MetaMask сам предложит переключиться на сеть Amoy при подключении кошелька.

## Как это работает

1. **Выпуск.** Авторизованная организация заполняет форму (адрес студента,
   название достижения, категория). Метаданные загружаются в IPFS, а в блокчейн
   записывается ссылка `ipfs://<CID>` и адрес владельца. Вызывается `issueBadge`.
2. **Портфолио.** Студент подключает кошелёк и видит все свои бейджи —
   приложение перебирает выпущенные токены и отбирает принадлежащие его адресу.
3. **Проверка.** Любой человек вводит номер бейджа (или сканирует QR) и через
   `verifyBadge` получает статус «подлинный / не найден», кто и когда выдал.
   Авторизация не нужна.

## Роли в контракте

- **Администратор** (`owner`) — разворачивает контракт, добавляет и удаляет
  организации-эмитенты (`addIssuer` / `removeIssuer`), может отозвать любой бейдж.
- **Эмитент** (issuer) — организация, которой разрешено выпускать бейджи.
- **Студент** — владелец бейджей, может их просматривать, но не передавать.

## Тесты

`npm test` проверяет: развёртывание, управление эмитентами, выпуск бейджей,
права доступа, публичную проверку, непередаваемость (soulbound) и отзыв.

## Безопасность и ограничения (соответствует паспорту проекта)

- Это **учебный MVP**. Контракт не проходил полный аудит безопасности.
- Работа только в **тестовой сети**, без реальных денег.
- Персональные данные и сканы документов **в блокчейн не записываются**.
- Никогда не коммитьте файл `.env` с приватным ключом в репозиторий.
