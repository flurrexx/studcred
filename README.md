# StudCred — NFT-портфолио студента

**StudCred** — прототип проверяемого цифрового портфолио студента. Достижения (курсы, мероприятия, практика, волонтёрство) фиксируются в виде NFT-бейджей в блокчейне. Любой человек может проверить подлинность бейджа по ссылке или QR-коду без регистрации.

🌐 **Демо:** https://studcred.vercel.app

---

## Архитектура и технологии

| Компонент | Технология |
|---|---|
| Смарт-контракт | Solidity 0.8.20, EVM Paris (совместимо с FACHAIN) |
| Блокчейн | FACHAIN (testnet, chainId 525) |
| Хранение метаданных | On-chain (прямо в блокчейне, без IPFS) |
| Фронтенд | React 18 + Vite + ethers.js v6 |
| Кошелёк | MetaMask |
| Деплой | Vercel |

**Логика хранения данных — полностью on-chain:**  
Название достижения, категория, дата выдачи и адрес эмитента записываются прямо в смарт-контракт. Никаких внешних хранилищ (IPFS, Pinata и т.д.) не используется — это делает бейджи самодостаточными и верифицируемыми без зависимостей.

---

## Функциональность

- **Портфолио студента** — галерея NFT-бейджей, фильтрация по категориям (курс, мероприятие, практика, волонтёрство)
- **Выпуск бейджа** — форма для авторизованных организаций (вуз, работодатель, организатор мероприятия)
- **Публичная проверка** — по номеру бейджа, по прямой ссылке (`?badge=N`), по QR-коду; без авторизации, без раскрытия лишних данных

## Быстрый старт (пользователь)

### Требования
- Браузер с расширением [MetaMask](https://metamask.io)
- Сеть FACHAIN добавлена в MetaMask (см. ниже)

### Добавить сеть FACHAIN в MetaMask

| Параметр | Значение |
|---|---|
| Имя сети | FACHAIN |
| RPC URL | https://rpc.finchainlab.ru |
| Chain ID | 525 |
| Символ валюты | FA |
| Обозреватель | https://explorer.finchainlab.ru |

MetaMask → выбор сети → Добавить сеть → Добавить вручную → заполнить поля выше.

### Просмотр портфолио
1. Откройте https://studcred.vercel.app
2. Нажмите «Подключить кошелёк» → подтвердите в MetaMask
3. На вкладке «Моё портфолио» отобразятся все бейджи вашего адреса
4. Используйте фильтры для просмотра по категориям

### Выпуск бейджа (для организации)
1. Подключите кошелёк организации (он должен быть авторизован администратором контракта)
2. Перейдите на вкладку «Выпустить бейдж»
3. Введите адрес кошелька студента, название достижения, выберите категорию
4. Нажмите «Выпустить бейдж» → подтвердите транзакцию в MetaMask
5. Через несколько секунд бейдж появится в портфолио студента

### Проверка бейджа (для работодателя / HR)
**Способ 1 — по ссылке:**  
Откройте ссылку вида `https://studcred.vercel.app/?badge=0` — проверка запустится автоматически.

**Способ 2 — по QR-коду:**  
Отсканируйте QR-код с карточки бейджа — откроется страница с результатом проверки.

**Способ 3 — вручную:**  
Перейдите на вкладку «Проверка бейджа», введите номер бейджа, нажмите «Проверить».

Результат проверки:
- ✅ **Бейдж подлинный** — название, категория, дата выдачи, адрес владельца и эмитента
- ❌ **Бейдж не найден** — бейдж не существует или был отозван

## Смарт-контракт

**Адрес контракта в FACHAIN:**  
`0x6FBf5ecF5BfcF33Bb6fbD1c5c3DeAA199e07479B`

**Основные функции:**

| Функция | Описание |
|---|---|
| `issueBadge(student, title, category)` | Выпустить бейдж (только авторизованный issuer) |
| `verifyBadge(tokenId)` | Проверить бейдж: valid, student, issuer, issuedAt, title, category |
| `revokeBadge(tokenId)` | Отозвать бейдж (owner или issuer) |
| `addIssuer(address)` | Авторизовать организацию (только owner) |
| `totalIssued()` | Общее количество выпущенных бейджей |

**Компиляция:**  
Solidity 0.8.20, `evmVersion: paris` — обязательно для совместимости с FACHAIN (сеть не поддерживает опкоды PUSH0/MCOPY из более новых версий EVM).

## Демонстрационный сценарий (сквозной)

**Участники:** Представитель вуза (организация), студент, работодатель (проверяющий)

### Шаг 1 — Выпуск бейджа
1. Представитель вуза открывает https://studcred.vercel.app
2. Подключает кошелёк организации (авторизованный issuer)
3. Вкладка «Выпустить бейдж»: вводит адрес студента, название «Призёр олимпиады по международным финансам», категория «Мероприятие»
4. Нажимает «Выпустить бейдж», подтверждает транзакцию в MetaMask
5. Статус: «✅ Бейдж успешно выпущен!»

### Шаг 2 — Отображение в портфолио
1. Студент открывает https://studcred.vercel.app
2. Подключает свой кошелёк
3. Вкладка «Моё портфолио» — отображается карточка бейджа: название, категория «Мероприятие», дата, эмитент
4. На карточке есть ссылка «Ссылка для проверки» — студент копирует её и отправляет работодателю

### Шаг 3 — Проверка подлинности
1. Работодатель получает ссылку `https://studcred.vercel.app/?badge=N`
2. Открывает её в браузере — **без установки MetaMask, без регистрации**
3. Видит: «✅ Бейдж подлинный», название достижения, дату, адрес эмитента и QR-код
4. При необходимости сканирует QR-код телефоном — получает тот же результат

**Сценарий пройден.** Данные в блокчейне, проверка публична, персональные данные студента не раскрываются (только адрес кошелька).

## Деплой контракта (для разработчиков)

```bash
# 1. Установить зависимости
npm install

# 2. Создать .env (скопировать из .env.example, вписать приватный ключ)
cp .env.example .env

# 3. Задеплоить в FACHAIN
npx hardhat run scripts/deploy.js --network fachain

# 4. Скопировать адрес контракта в frontend/src/contract-address.json
```

**Важно при компиляции через Remix:**  
Solidity Compiler → Advanced Configurations → EVM Version → выбрать **`paris`**  
(без этого контракт не исполняется в FACHAIN из-за несовместимых опкодов)

## Ограничения и допущения

- Проект использует тестовую сеть FACHAIN, реальных денег нет
- Мобильное приложение и HR-интеграции не входят в MVP
- Персональные данные в блокчейн не пишутся — только адрес кошелька и текст достижения
- Массовая выдача бейджей по списку — направление дальнейшего развития
